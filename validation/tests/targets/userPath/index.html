Form whose completion reveals defects

A recorded user path fills the name, chooses a color, and activates Continue. The name input has only a placeholder as its label (a defect the testaro phOnly rule reports). Continuing inserts a section containing a link without a destination and an image whose alternative text is a URL (defects the linkTo and altScheme rules report), so a test act at a checkpoint after the activation reports defects that one before it does not.
